# Build 246 — restauración completa de módulos

- Basado en la versión anterior al rediseño.
- Si un negocio tiene todas sus funciones efectivas desactivadas, recupera el catálogo completo, incluida Notificaciones.
- Nuevos negocios reciben el catálogo completo disponible.
- No borra clientes, negocios, citas, rifas, publicidad ni estadísticas.
