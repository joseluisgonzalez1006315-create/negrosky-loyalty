# Build 186 · Papelera de clientes y sesión automática

- Clientes activos: negocio y administrador general pueden enviar a papelera.
- Papelera: negocio y administrador general pueden restaurar clientes.
- Eliminación definitiva: solo administrador general; crea respaldo automático antes de borrar.
- Estadísticas: botón para borrar datos del periodo, visible y utilizable solo por administrador general.
- Inicio de sesión: campos vacíos; sesión válida se reanuda automáticamente con indicador visual.
- Si el token expiró, se muestra el formulario vacío sin borrar sesiones válidas por errores temporales.
