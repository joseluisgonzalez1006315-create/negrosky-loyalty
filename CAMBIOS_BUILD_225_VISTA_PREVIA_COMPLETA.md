# Build 225 · Vista previa completa del cliente

- Se añadió al editor la barra superior real del cliente: Más negocios, Fidelización, Premios, Horarios, Reservar y Perfil.
- La barra respeta los módulos activos y las opciones visibles del negocio.
- Al tocar un botón superior en la vista previa se selecciona el módulo correspondiente para editarlo.
- La vista previa ahora mantiene el mismo orden visual de la página pública: encabezado, accesos superiores y contenido.
