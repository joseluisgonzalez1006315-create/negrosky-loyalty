# Build 191 — Totales estadísticos editables

- Se quitaron los botones de editar de cada registro individual.
- El administrador general puede editar los cinco totales de estadísticas del periodo seleccionado.
- Los totales manuales se guardan en una tabla pequeña: un registro por negocio y periodo.
- Se mantiene el conteo automático de eventos para periodos sin ajuste manual.
- Los eventos de analítica se limpian automáticamente después de 90 días para evitar crecimiento indefinido.
- Borrar estadísticas también elimina el ajuste manual del negocio o de todo el sistema.
