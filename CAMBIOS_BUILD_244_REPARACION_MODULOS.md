# Build 244 — reparación segura de módulos

- Detecta negocios con todos los módulos en falso aunque ya tengan datos existentes.
- Reconstruye únicamente ese estado inconsistente usando evidencia real de programas, rifas, ruleta, citas, venta por tiempo, notificaciones, branding y colaboraciones.
- Fidelización y página pública quedan activas en una recuperación de negocio existente.
- La respuesta de `/api/tenant-modules` informa si se reparó el estado.
- El panel muestra el aviso de recuperación y conserva las elecciones parciales existentes.
