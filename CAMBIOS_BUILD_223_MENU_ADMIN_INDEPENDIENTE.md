# Build 223 · Menú administrativo independiente

- La selección de módulos del cliente ya no oculta las herramientas del panel administrativo.
- Superadministradores, administradores de negocio y administradores de sucursal pueden ver todas las secciones del panel.
- Los permisos de seguridad siguen aplicándose en la API y los trabajadores conservan sus módulos autorizados.
- La página del cliente mantiene su configuración de módulos por negocio.
