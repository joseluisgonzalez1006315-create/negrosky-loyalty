# Build 261 — Módulos visibles y botones estables

- La barra de accesos se actualiza automáticamente según los módulos y contenido disponibles.
- El botón Premios se oculta cuando no hay premios ni rifas visibles.
- Reservas, horarios y fidelización aparecen solo cuando están disponibles.
- Se añadió sincronización de visibilidad para evitar que la primera pulsación falle mientras cargan los datos.
