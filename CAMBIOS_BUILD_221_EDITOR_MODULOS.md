# Build 221 · Editor visual y módulos opcionales

- “Más negocios” queda como primer acceso en la barra rápida del cliente.
- La vista previa del editor permite seleccionar directamente Premios, Horarios, Reservar, Rifas y los demás módulos con un clic.
- Se conservan los controles de visibilidad, orden y ancho por celular y PC.
- “Reservar” permanece oculto mientras el negocio no tenga el módulo activo, una sucursal activa y al menos un servicio de citas activo.
- Si la configuración de reservas falla o no existe, no se muestra un botón vacío al cliente.
- Se actualizaron las versiones de caché del panel y la página del cliente.
