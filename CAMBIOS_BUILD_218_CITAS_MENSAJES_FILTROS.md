# Build 218 · Mensajes libres, historial y filtros

- El cliente puede escribir un mensaje libre antes de enviarlo por WhatsApp.
- En “Cancelar cita” aparece un botón para escribir y enviar el mensaje por WhatsApp usando el motivo escrito.
- La X del cliente elimina del historial las citas canceladas.
- La X del negocio elimina las citas canceladas, completadas o marcadas como no asistió. Las citas activas no se pueden borrar.
- El panel de citas incluye filtros por fecha “Desde” y “Hasta”.
- Se conserva la agenda, los avisos y el resto de funciones existentes.
