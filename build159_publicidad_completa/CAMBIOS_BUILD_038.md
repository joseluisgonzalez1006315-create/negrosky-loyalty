# CAMBIOS · BUILD 038

- La página pública del cliente ahora interpreta el ancho **y la posición** de cada módulo guardados en el diseñador, igual que la vista previa.
- Se usa una cuadrícula común de 12 columnas en la página real y en la previsualización.
- Se actualizó la versión de los archivos web para que el celular descargue los estilos y scripts nuevos, evitando que muestre una versión anterior en caché.
- Se eliminó el texto informativo de horario que no correspondía con la vista compacta móvil.

## Prueba recomendada

1. En el panel, selecciona **Celular** en la vista previa y guarda el diseño.
2. Abre la URL pública en el teléfono y actualiza una vez.
3. Confirma que el orden, ancho y alineación coincidan con esa vista previa.
