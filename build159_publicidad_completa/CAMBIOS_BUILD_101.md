# Build 101 – Editor completo de rifas

- Sustituye los cuadros de preguntas por un editor visual completo.
- Permite modificar todos los datos de la rifa.
- Permite cambiar o quitar la foto del premio.
- Permite cambiar o quitar la foto de entrega del ganador.
- Incluye vista previa de ambas imágenes antes de guardar.
