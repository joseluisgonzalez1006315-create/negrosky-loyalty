# Beta online gratuita

Esta modalidad publica temporalmente la plataforma usando Cloudflare Quick Tunnel.

## Requisitos

- NEGROSKY iniciado en `http://127.0.0.1:8030`.
- El computador debe permanecer encendido y conectado a Internet.
- Descargar `cloudflared.exe` para Windows desde la página oficial de Cloudflare.

## Uso

1. Guarda `cloudflared.exe` en esta carpeta.
2. Ejecuta `ABRIR_NEGROSKY_ONLINE.bat`.
3. Copia la dirección `https://...trycloudflare.com` que aparecerá.
4. Comparte esa dirección con los usuarios beta.

La dirección cambia cada vez que se cierra el túnel. Esta modalidad es para pruebas; no debe usarse todavía como servicio comercial definitivo. Antes de compartirla, cambia la contraseña del administrador y no compartas el panel de administración.
