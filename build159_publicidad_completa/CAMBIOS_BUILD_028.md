# CAMBIOS · BUILD 028

## Personalización pública por negocio

- Redes: teléfono, WhatsApp, Instagram, Facebook, TikTok, sitio web y Google Maps.
- Dirección y horario público, sincronizado desde **Horarios y módulos**.
- Los botones sin datos no se muestran y los enlaces web exigen `https://` o `http://`.
- Imagen de fondo con encuadre compartido o independiente para celular y escritorio: cubrir o mostrar completa, posición horizontal y vertical.
- Opacidad propia para la foto de fondo y capa de oscurecimiento para conservar la lectura.
- Logo configurable: forma cuadrada, redondeada o circular; ajuste completo o recortado; tamaño, opacidad y color de fondo.

## Control por campaña

El diseñador visual conserva los valores generales de la tarjeta. En cada campaña se puede seleccionar para cada parte:

- Usar diseño general.
- Mostrar siempre.
- Ocultar siempre.

Las opciones están disponibles para título o banner, sellos, barra de progreso, premio/disponibilidad y botón de compra. Una decisión explícita de campaña tiene prioridad sobre el editor general.

## Compatibilidad y migración

- Las nuevas columnas se agregan automáticamente sin borrar bases antiguas.
- La página del cliente se actualiza automáticamente y muestra el mismo diseño en PC, Android y iPhone.
- Se conserva la lógica de compras, QR, premios, citas, roles y separación por negocio.
