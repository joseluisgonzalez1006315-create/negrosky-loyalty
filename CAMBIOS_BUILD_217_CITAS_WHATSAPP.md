# Build 217 · WhatsApp directo y borrado de citas

- El botón de WhatsApp usa apertura directa de la aplicación en Android/iPhone cuando está instalada; en equipos sin la aplicación usa el enlace web.
- Los enlaces de WhatsApp de citas ya no abren una pestaña adicional desde el panel móvil.
- Se conservaron los mensajes con emojis y se muestran con texto completo.
- La X del negocio elimina del registro las citas canceladas, completadas o marcadas como no asistió, con confirmación.
- Las citas programadas o confirmadas no se pueden borrar por accidente.
- La X del cliente continúa ocultando solamente la cita cancelada en su propia pantalla.
