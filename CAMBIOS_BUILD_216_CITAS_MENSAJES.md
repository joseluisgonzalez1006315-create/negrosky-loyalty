# Build 216 · Citas, excusas y avisos

- El aviso por WhatsApp del cliente queda visible desde la tarjeta de la cita, sin tener que abrir primero el formulario de cancelación.
- El cliente puede enviar una excusa por WhatsApp al negocio desde su cita.
- El negocio puede enviar por WhatsApp al cliente el motivo de una cancelación.
- El motivo de una cancelación del negocio se conserva y se muestra en la página del cliente.
- Las citas canceladas tienen una X para ocultarlas visualmente en el cliente y en el panel administrativo. Ocultarlas no borra el historial ni la cita de la base de datos.
- Se mantienen las demás funciones y la agenda ampliada del Build 215.
