# Build 260 — Botones de módulos con abrir/cerrar

- Fidelización, Premios, Horarios y Reservas ahora funcionan como botones alternables.
- Al pulsar un botón se abre su módulo; al pulsarlo otra vez se oculta.
- Se mantiene la carga de agenda al abrir Reservas.
- Se conserva el acceso a editar perfil y cerrar sesión.
