# CAMBIOS · BUILD 030

## Editor manual

- Clic sobre un módulo en la vista previa para seleccionarlo.
- Arrastrar módulos para cambiar el orden visual.
- Ajuste independiente de ancho para celular y PC.
- El orden y el tamaño se guardan por negocio.
- Vista previa utiliza el dispositivo elegido antes de guardar.
- Corregido el editor para aceptar de forma segura los anchos internos y guardados; ya no presenta el error de `split` al seleccionar, arrastrar o redimensionar.

## Experiencia en PC y móvil

- Escritorio usa hasta 1180 px y distribuye módulos en columnas sin que el espacio entre ellas fuerce una segunda fila.
- La vista previa de escritorio alcanza 1080 px, para mostrar una composición de PC real.
- Celular conserva módulos a ancho completo para lectura y uso táctil.
- La vista previa del panel mantiene su propio desplazamiento en pantallas grandes; no queda perdida al bajar el formulario.

## Redes

- Reemplazo de símbolos de texto por iconos vectoriales para teléfono, WhatsApp, Instagram, Facebook, TikTok, web y ubicación.
- Mantiene las opciones compactas de BUILD 029: solo icono, texto o ambos, tamaño y posición flotante.

## Seguridad

- Migración automática para el orden y ancho de módulos.
- No cambia compras, QR, premios, citas, roles ni la separación por negocio.
