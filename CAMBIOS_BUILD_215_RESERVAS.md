# Build 215 · Reservas y avisos

Cambios incluidos:

- La agenda de trabajadores muestra todas las citas activas de los próximos 31 días, con un límite amplio para evitar que desaparezcan citas cuando hay varias.
- El negocio puede cancelar una cita con un motivo opcional. El motivo queda guardado en la cita y se muestra al cliente en “Mis citas”.
- Al cancelar desde el panel del trabajador aparece un botón opcional para enviar al cliente el motivo por WhatsApp.
- El cliente puede avisar al negocio por WhatsApp desde la misma cita antes de cancelarla.
- El panel administrativo incluye el motivo del negocio en el mensaje de WhatsApp de las citas canceladas.

No se cambiaron tablas ni se eliminaron funciones existentes.
