# CAMBIOS · BUILD 029

## Módulos compactos de redes

- Iconos integrados para teléfono, WhatsApp, Instagram, Facebook, TikTok, sitio web y ubicación.
- Opción para mostrar solo el logo, solo texto o ambos.
- Tamaño pequeño, mediano o grande.
- Ubicación dentro de la sección o como botones flotantes.
- Esquina configurable: superior/inferior, izquierda/derecha.
- Visibilidad independiente para celular y PC.

## Orden visual del cliente

En Diseño visual se puede elegir un orden diferente para celular y escritorio para:

- Contacto, redes y horario.
- Perfil.
- Campañas y tarjetas.
- Premios.
- Citas o reservas.

La vista previa usa el orden del dispositivo seleccionado. Se conserva el funcionamiento de cada módulo y las prioridades por campaña del BUILD 028.

## Seguridad y compatibilidad

- Migración automática de las nuevas opciones por negocio.
- Enlaces de redes protegidos por validación de URL.
- Sin cambios en compras, QR, validación de premios, agenda, roles o datos históricos.
