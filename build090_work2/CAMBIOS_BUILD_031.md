# CAMBIOS · BUILD 031

## Corrección real de módulos

- Contacto, redes y horario ahora se incorporan al mismo lienzo de módulos del cliente.
- Su orden y ancho se aplican de verdad en la página pública, no solo en la vista previa.
- El ajuste de ancho para celular ya no queda anulado por una regla fija de 100 %.
- PC y celular mantienen configuraciones de orden y ancho independientes.

## Control con mouse

- Arrastrar un módulo en la vista previa ya registra la transferencia del navegador y actualiza el orden correcto.
- El destino del arrastre se resalta antes de soltar.
- Cada módulo seleccionado muestra el control ↔: arrástralo horizontalmente para cambiar el ancho en la vista activa.

## Conservación

- No se modifica la lógica de compras, premios, QR, trabajadores, citas, roles, sucursales ni base de datos.
